# Judge

You are judging this review packet:

- `goal.md`: the objective, required outcomes, and constraints.
- `project/`: a snapshot of the project.

Evaluate `project/` against `goal.md` as you find it. Choose your verification
actions and give concrete evidence for a score from 0.0 to 100.0. List unmet
required outcomes. Unobserved behavior remains unverified.

Stay inside this folder and don't save memories; each review starts fresh. The
snapshot is a disposable copy: install, build, and run it as needed, but judge
the files as submitted.

Write `result.json` here with these fields, then end the session:

```text
score: 0.0–100.0
unmet_required: required outcomes still unmet
evidence: concrete observations
feedback: concise deficiencies for the next revision
```
